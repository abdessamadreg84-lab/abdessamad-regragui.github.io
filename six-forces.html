THE SIX FORCES

How does a relation
change the position?

Six functional lenses for seeing how relationships between pieces, squares, constraints, and duties can transform a chess position.

THE IDEA

Force is about what a relation can do.

An attack, support, block, duty, or dependency is not merely a static fact. It can create pressure, restrict possibilities, redirect a piece, release an existing capability, or create competing demands.

RELATION → FORCE → POSSIBLE CHANGE

The six forces are a vocabulary for describing these transformations.

These six categories are proposed within this framework. They are not an established taxonomy of chess.

THE SIX

Six ways a relation can act.

Push

Drives the position toward a response or new state.

Pull

Draws a piece, target, or structure toward a destination or state.

Redirect

Changes the direction or duty of an existing force.

Release

Removes a constraint and activates a capability.

Tension

Concentrates competing demands that remain unresolved.

Block

Prevents a capability from expressing itself.

01 · PUSH

Push drives the position toward a response.

A relation can make the current state increasingly difficult to maintain. The opponent is pushed toward responding, moving, exchanging, defending, or changing the position.

PRESSURE → RESPONSE

A check is an obvious example. The king must respond because the current state cannot simply remain unchanged.

Question

What is this relation forcing the position to do?

Direction

Toward a new state in which the pressure has been answered or transformed.

02 · PULL

Pull makes another state or destination attractive or necessary.

A relation can make a particular square, piece, or structure increasingly relevant. A sacrifice may draw a king toward a vulnerable area. A weakness may draw a defender toward a particular task.

RELATION → DESTINATION / STATE

“Pull” is a functional metaphor. It does not mean that chess pieces exert literal attractive forces.

CURRENT STATE → PULLED TOWARD ANOTHER STATE

03 · REDIRECT

Redirect changes what an existing force is doing.

A piece may already have an important relationship with the position. A tactical transformation can change its direction, target, or duty.

OLD RELATION → CHANGE → NEW RELATION

Deflection is a familiar example. A defender is forced away from one responsibility, changing the relationships that remain behind.

Before

A piece performs one important function.

After

The piece's duty or direction has changed, creating a different relational structure.

04 · RELEASE

Release removes a constraint.

One of the most important ideas in the framework is that a capability can already exist while being unable to express itself.

CAPABILITY + CONSTRAINT → REMOVE CONSTRAINT → CAPABILITY RELEASED

The classic example is a discovered attack. The attacking relationship already exists, but another piece blocks its expression.

ATTACK + BLOCK → MOVE BLOCKER → RELEASE ATTACK

The key question becomes:

What is already there, but currently unable to act?

05 · TENSION

Tension concentrates competing demands.

A position can contain several relationships that cannot all be satisfied simultaneously.

COMPETING DEMANDS → UNRESOLVED TENSION

A defender may protect two pieces. A piece may have several duties. Multiple attackers may compete for the same point. A pawn structure may contain conflicting possibilities.

Duty

A piece must remain connected to something important.

Conflict

Another demand pulls the same piece toward a different task.

Potential

A future change may resolve the tension and transform the position.

06 · BLOCK

Block prevents a capability from expressing itself.

A blocker suppresses a relationship that would otherwise be available.

FORCE → BLOCK → SUPPRESSED EXPRESSION

A piece can block a rook's line. A pawn can block a file. A defender can block access to a square. A duty can function as a practical constraint even without a physical obstruction.

What cannot happen because something is in the way?

THE RELATIONSHIP BETWEEN THEM

The forces can transform into one another.

The six forces should not be treated as six isolated move categories. One transformation can create another.

TENSION → REDIRECT → RELEASE → PUSH → RESULTANT

Or:

BLOCK → REMOVE BLOCK → RELEASE → ATTACK

Or:

DUTY → REDIRECT → NEW WEAKNESS → PUSH

ONE MOVE, SEVERAL FORCES

A move does not have to belong to only one category.

A single move may remove a blocker, redirect a defender, create tension, and push the opponent toward a response simultaneously.

Release

A line becomes available.

Redirect

A defender's duty changes.

Push

The opponent must respond to the new pressure.

The useful object of analysis is therefore the transformation of the relational network, not the label attached to the move.

FORCE VS RESULT

What can happen is different from what actually happens.

Force

POTENTIAL

What a relation is capable of doing to the position.

Resultant

ACTUAL OUTPUT

What interacting relations actually produce.

FORCE → POSSIBLE CHANGE → INTERACTION → RESULTANT

TENSE

Current force and future force are different.

A force can be active now or conditional on a future change. This distinction prevents us from treating every possible tactical idea as though it already exists.

Active

The relation can currently express itself.

Conditional

The relation becomes available only after a state transformation.

CURRENT FORCE ≠ CONDITIONAL FORCE

THE SIX FORCES IN CALCULATION

Calculation follows forces through changing states.

RECALCULATE THE POSITION

PRACTICAL QUESTIONS

Use the forces as questions.

Push

What is being forced to respond?

Pull

What is being drawn toward another state?

Redirect

Whose direction or duty can change?

Release

What capability is currently blocked?

Tension

What competing demands are unresolved?

Block

What prevents an available force from expressing itself?

THE BIGGER LOOP

Forces are part of a recursive position model.

REACH → OCCUPANCY → CONSTRAINT
→ FORCE → TENSE → RESULTANT
→ CHANGE → REACH

The final step returns to reach because every meaningful transformation creates a new position with a new network of possibilities.

DIRECTION · OBSTACLE · MECHANISM

The forces become useful when connected to purpose.

Direction

Where should the position go?

Obstacle

What prevents that desired state?

Mechanism

Which force can transform the obstacle?

DIRECTION → OBSTACLE → FORCE → CHANGE

About the framework

The Six Forces are proposed vocabulary within this framework, not an established taxonomy of chess. They are intended as functional lenses for organizing perception and calculation, not as replacements for traditional chess concepts or analysis.
